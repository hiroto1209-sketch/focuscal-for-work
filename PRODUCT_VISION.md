# FocusCal for Work — Product Vision

## Why FocusCal exists

予定管理が苦手な人が、「予定を管理できない自分」を責めるのではなく、**次のひとつに集中して前に進める**ためのアプリ。

## Core promise

> 予定を並べるだけではなく、ひとつずつ終わらせる。

## UX principles

1. **見た瞬間に次にやることが分かる**
2. **入力の手間を極限まで減らす**
3. **情報を詰め込みすぎず、認知負荷を下げる**
4. **完了を肯定的にフィードバックする**
5. **失敗や未完了を責めない**
6. **スマートフォンだけでも主要操作が完結する**
7. **初心者にも、ヘビーユーザーにも使える**

## Product direction

### Phase 1 — UI first
- Calendar
- Daily agenda
- Quick event creation
- Completion interaction
- Mobile-first navigation
- Accessible visual hierarchy

### Phase 2 — Focus experience
- Next action / Focus mode
- Streak and progress
- Gentle reminders
- Recurring tasks
- Search and filters

### Phase 3 — Reliable data
- IndexedDB / local-first storage
- Backup and restore
- Data migration
- Offline-first PWA

### Phase 4 — Connected calendar
- External calendar integrations
- Optional account / cloud sync
- Sharing

## Non-goals

FocusCal should not become a complicated dashboard that requires users to maintain the app itself. Every new feature must justify its cognitive cost.
